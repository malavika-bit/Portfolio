## 🚀 Publishing to GitHub Pages

1. **Commit and push your files**:
   ```bash
   git add index.html style.css script.js profile.png Malavika_Cv_Europass.pdf README.md
   git commit -m "Deploy Europass-themed portfolio website"
   git push origin main
   ```

2. **Enable GitHub Pages**:
   - Go to your repository on GitHub: `https://github.com/malavika-bit/Portfolio`
   - Click **Settings** > **Pages** (in the left sidebar).
   - Under **Build and deployment** > **Branch**, select `main` branch and `/ (root)` folder.
   - Click **Save**.
   - In 1–2 minutes, your website will be live at:  
     👉 **[https://malavika-bit.github.io/Portfolio/](https://malavika-bit.github.io/Portfolio/)**
